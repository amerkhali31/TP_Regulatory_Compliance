1. all cells must be populated (except for cells in the weight/volume column and the price column - those are conditionally populated)
2. Differece between reporting and liability must be 0
3. Fed description column must be populated only with values from this list: ROLL YOUR OWN, LARGE CIGAR, OTHER, VAPOR PRODUCT, CHEWING TOBACCO, PIPE TOBACCO, SMALL CIGAR, SNUFF, ALTERNATIVE NICOTINE PRODUCT, E-LIQUID PRODUCT
4. Unit of Measure column must be populated only with values from this list: PAK, STK, BOX, ECH, BAG, TIN, FOI, CAN, BUL, TUB, PCH, BUN, PLG, CUT, BOT, JAR, OTH
5. Unit description column must be populated only with values from this list: PAK, STK, BOX, ECH, BAG, TIN, FOI, CAN, BUL, TUB, PCH, BUN, PLG, CUT, BOT, JAR, OTH
6. No UPC should exceed 20 characters nor be less than 12 characters
7. Manufacturer column cannot be N/A
8. Customer FEIN and Customer ID column must not be empty, N/A, 99999, or any other filler entry. Must be legitamite data.
9. Full instructions can be found here: https://tax.illinois.gov/forms/excise/tobacco/form-tp-1-il-instr.html
